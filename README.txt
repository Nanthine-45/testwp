PLAYNEST TOY SHOP WEBSITE

HOW TO OPEN
1. Extract PlayNest_Toy_Shop.zip.
2. Open the extracted folder.
3. Double-click index.html to preview the website in your browser.

CUSTOMIZE YOUR WHATSAPP NUMBER
1. Open script.js in Notepad or any code editor.
2. Find: const WHATSAPP_NUMBER = "";
3. Enter your number with country code and digits only.
   Example India: const WHATSAPP_NUMBER = "919876543210";
4. Save the file and refresh the website.

CUSTOMIZE PRODUCTS
Open script.js and edit the products array. Each product has:
- name
- category (Soft Toys, Learning, Building, Vehicles, Creative)
- price
- tag
- image (image URL)

IMPORTANT
- This is a front-end starter website. It includes product filtering, search, a working demo cart and WhatsApp order message.
- It does not include online payment processing, customer accounts, inventory management, an admin dashboard or a server/database.
- Product photos are loaded from external image URLs, so an internet connection is needed to display them.
- To publish online, upload the extracted files to a static hosting provider or your web hosting account.
- Replace demo products, images and contact details before launching.
